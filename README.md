# 📸 Picsum Gallery App

A Flutter photo gallery app powered by the Picsum Photos API. Browse beautiful photographs, explore photo details, and save your favourite images for later.

## ✨ Features

- Browse photos fetched from the Picsum API.
- Beautiful two-column masonry photo grid.
- View detailed photo information.
- Add and remove photos from favourites.
- Dedicated favourites page.
- Save favourite selections locally using SharedPreferences.
- Download photos to the device gallery.

## 🛠️ Technologies Used

- Flutter
- Dart
- REST API
- Cubit (State Management)
- SharedPreferences
- HTTP
- Flutter Staggered Grid View
- Google Fonts
- Gal

## 🚀 Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/sharmia-123/picsum_gallery.git
   ```

2. Navigate to the project folder:

   ```bash
   cd picsum_gallery
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the app:

   ```bash
   flutter run
   ```
